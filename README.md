<p align="center">
Sou <strong>Djames Suhanko</strong>. No <strong>Clave Sol</strong>, reúno partituras, conhecimento, ferramentas e aplicativos para quem aprende, ensina e toca. Meu trabalho conecta a prática musical ao desenvolvimento de software.
</p>
